# Textos de licença / Licence texts

Cópias dos textos das licenças citadas nos cabeçalhos `SPDX-License-Identifier` e nos avisos do projeto (fonte: [SPDX license list](https://github.com/spdx/license-list-data)). Nos textos MIT, BSD e zlib os campos `<year>` / `<copyright holders>` são do texto-modelo: o titular de cada arquivo está no cabeçalho do próprio arquivo ou no `PROVENANCE.md` / `NOTICE` da sua pasta. Veja [CREDITS.md](../CREDITS.md) e [NOTICE.md](../NOTICE.md).
