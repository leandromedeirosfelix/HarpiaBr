# Segurança / Security

**Português:** se encontrar uma vulnerabilidade (por exemplo, no Builder, na extração do `.nup`, no carregamento de DLLs ou em algo que execute código inesperado), **não abra uma issue pública**. Use **Security → Report a vulnerability** neste repositório (relato privado do GitHub). Descreva o que é, como reproduzir e o impacto. Respondemos assim que possível.

**English:** if you find a vulnerability (for example in the Builder, `.nup` extraction, DLL loading, or anything that runs unexpected code), **do not open a public issue**. Use **Security → Report a vulnerability** on this repository (GitHub private reporting). Describe what it is, how to reproduce it and the impact. We will reply as soon as we can.

Fora do escopo / out of scope: pedidos relacionados a pirataria, chaves ou obtenção do jogo; piracy, keys or game-acquisition requests.
